# Changelog

All notable changes to PatchPilot are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-07-14

### Added

- `LICENSE` (MIT) file
- `SECURITY.md` with a private advisory reporting channel
- `CHANGELOG.md` (this file)
- `CONTRIBUTING.md` with contribution and review workflow
- `CODE_OF_CONDUCT.md`
- `AGENTS.md` so the kit dogfoods its own operating contract
- `.github/PULL_REQUEST_TEMPLATE.md` that mirrors `templates/PR_TEMPLATE.md`
- `.github/ISSUE_TEMPLATE/bug_report.md`
- `.github/ISSUE_TEMPLATE/feature_request.md`
- `.github/ISSUE_TEMPLATE/skill_request.md`
- `.github/workflows/validate-pack.yml` CI workflow that runs
  `scripts/validate_pack.py` on every push and pull request
- `scripts/validate_pack.py` Python 3 script that regenerates
  `VALIDATION_REPORT.md` and exits non-zero on failure
- `scripts/build_zip.py` Python 3 script that produces a clean release
  zip without macOS metadata, editor backups, or stale build output
- `examples/node-cli.md` stack preset for Node.js CLI repositories
- `examples/python-lib.md` stack preset for Python library repositories
- `examples/monorepo.md` stack preset for monorepos
- `docs/INTEGRATION.md` deep-dive on ChatGPT Project setup
- `FAQ.md` with answers to common questions

### Changed

- `MANIFEST.json` bumped to 1.1.0 with the new file list and counts
- `VALIDATION_REPORT.md` regenerated by the validation script
- `README.md` updated to describe the new tooling, examples, and CI
- The existing 26-file v1.0.0 content remains unchanged

### Removed

- The stale `chatgpt-pr-only-github-agent-pack.zip` artefact from
  earlier iterations is no longer tracked. The release zip is now
  produced on demand by `scripts/build_zip.py`

## [1.0.0] - 2026-07-13

### Added

- Initial 26-file release of the PatchPilot kit
- `SYSTEM_PROMPT.txt` (7,372 characters, under the 8,000 limit)
- `SKILLS_INDEX.md` dispatcher
- 9 skill files under `skills/`
- 5 templates under `templates/`
- 7 task-starter prompts under `prompts/`
- `README.md`, `MANIFEST.json`, `VALIDATION_REPORT.md`
